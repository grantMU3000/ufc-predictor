## Key ideas
- Async allows code to perform multiple tasks concurrently
- Sync performs tasks one after the other
- Async allows you to do other work while waiting for things like Database queries or networ responses
- Async doesn't help with computing processes (e.g. calculations) 
- Helps when you're handling multiple API requests at the same time
- Choose based on what your specific API route does
    - Async still needs you to await the function in order to perform operating tasks
